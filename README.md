# Aisseveryday v7 — день, даты, календарь и саммари

Собрано поверх последнего рабочего комплекта файлов без изменения таблицы Supabase.

Что добавлено:
- новый экран «Сегодня» по визуальным референсам: кольцо сфер, крупный прогресс, лента дат, яркие карточки;
- можно открывать любой день и добавлять задачу сразу туда;
- в недельной задаче можно задать дату и время;
- задача недели с датой автоматически появляется в выбранном дне;
- у задач есть «•••»: завтра, через неделю, произвольная дата/время, оставить в неделе без даты;
- просроченные незакрытые задачи показываются отдельным блоком и не пропадают;
- экспорт задачи в календарь устройства через .ics (одностороннее добавление);
- тип результата: тренировка, книга, бриф, прогулка, шаги, занятие и др.;
- итоги недели и месяца автоматически собирают выполненные результаты в яркие карточки;
- у новых выполнений сохраняется completedAt, чтобы саммари по периодам становились точнее;
- существующие старые задачи без даты остаются видны в «Сегодня» и не мигрируются автоматически;
- существующая иерархия год → месяц → неделя → день, желания и ретро сохранены.

Важно: календарный экспорт .ics — это не двусторонняя синхронизация. Для настоящей синхронизации изменений из Apple/Google Calendar обратно в планер понадобится отдельная интеграция.

Для GitHub заменить: index.html, styles.css, app.js.
