# Мой навигатор — Telegram Mini App MVP

Это статический MVP личного планера: Сегодня → Неделя → Месяц → Мой год.

## Что уже работает

- задачи на сегодня и неделю;
- галочки и сохранение выполненного;
- быстрый ввод задачи;
- три годовых направления;
- цели месяца;
- 50 желаний;
- месячное ретро;
- ачивки;
- история года;
- Telegram theme colors;
- haptic feedback внутри Telegram;
- Telegram CloudStorage с fallback на localStorage в обычном браузере.

## Как посмотреть локально

Нужен любой простой web server. Из папки проекта:

```bash
python3 -m http.server 8000
```

Открыть:
http://localhost:8000

Просто двойной клик по index.html тоже обычно работает, но локальный сервер надёжнее.

## Как опубликовать

Подойдёт любой HTTPS-хостинг статических файлов: GitHub Pages, Cloudflare Pages, Vercel, Netlify и т.п.

После публикации у вас будет адрес вроде:
https://your-domain.example/

Telegram Mini App должен открываться по HTTPS URL.

## Как подключить к Telegram

1. Создать бота через @BotFather.
2. Опубликовать эту папку на HTTPS.
3. В @BotFather выбрать бота и настроить Main Mini App / Web App, указав опубликованный URL.
4. Можно также сделать menu button, который открывает Mini App.

После этого интерфейс будет открываться прямо внутри Telegram.

## Важно про данные

Сейчас MVP хранит состояние одной JSON-записью `navigator_state_v1`.

В Telegram используется `Telegram.WebApp.CloudStorage`.
В обычном браузере — `localStorage`.

Это подходит для личного MVP. Для более серьёзной версии лучше добавить backend и базу данных, особенно если нужны:
- доступ с Telegram и веба с полностью общей синхронизацией;
- история изменений;
- сложная аналитика;
- автоматические напоминания от бота;
- импорт календаря;
- несколько пользователей.
