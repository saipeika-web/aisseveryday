# Aisseveryday v6.1 — safe migration fix

Это исправление v6, которое НЕ должно заменять существующие пользовательские данные.

Что исправлено:
- возвращена отсутствовавшая функция фильтров (`filterHtml`) — именно из-за неё рендер v6 падал до вывода задач;
- существующий JSON из `planner_state` загружается как источник истины;
- новые поля v6 (`monthThoughts`, `monthPlans`) достраиваются поверх старых данных;
- перед нормализацией создаётся локальная резервная копия JSON в браузере:
  `aisseveryday_supabase_backup_latest`;
- ретро показывает реальное число заведённых желаний, а не `/50`;
- при простом открытии приложения база не перезаписывается. Запись происходит только после пользовательского действия.

Для обновления GitHub Pages достаточно заменить:
- `app.js`

`index.html` и `styles.css` из v6 можно оставить текущими.
