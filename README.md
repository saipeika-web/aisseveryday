# Aisseveryday v5 — Неделя → День

Главная новая механика:

1. В «Неделе» у обычной задачи есть кнопка «Разбить».
2. Нажимаешь её — задача превращается в задачу с прогрессом.
3. Добавляешь шаги: «Зарядка 1», «Зарядка 2», «Зарядка 3», «Зарядка 4».
4. У каждого шага выбираешь день текущей недели.
5. В назначенный день шаг автоматически появляется в «Сегодня».
6. Галочка в «Сегодня» одновременно обновляет прогресс недельной задачи.

Важно: это одна и та же подзадача, а не копия, поэтому синхронизация идёт в обе стороны.

Также сохранены:
- Supabase-синхронизация;
- сферы;
- 50 желаний;
- цели года;
- ретро месяца.
