# Aisseveryday v3 — сферы + 50 желаний

Что добавлено:
- сфера у каждой задачи;
- фильтры задач по сферам;
- связь задачи с одной из 3 целей года или с конкретным желанием;
- полноценный список «50 желаний»;
- желание можно включить в текущий месяц;
- из желания можно одним нажатием создать связанную задачу на сегодня;
- у желания виден прогресс связанных задач;
- в «Мой год» появился баланс сфер;
- старые данные из Supabase автоматически нормализуются и не должны пропасть.

Для GitHub Pages замените index.html, styles.css и app.js.
