# Aisseveryday v2 — Supabase sync

Теперь веб-версия и Telegram Mini App используют одну таблицу `planner_state`.

## Что заменить на GitHub
- `index.html`
- `styles.css`
- `app.js`

## Первый вход
1. Создать аккаунт через email + пароль.
2. Если Supabase требует подтверждение email — открыть письмо.
3. Войти тем же email + паролем в Telegram и браузере.

## Проверка
Добавь задачу `ТЕСТ СИНХРОНИЗАЦИИ` в Telegram, подожди секунду, затем обнови веб-версию. Задача должна появиться.
