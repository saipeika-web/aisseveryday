# Telegram setup — коротко

## 1. Создайте бота
Откройте @BotFather → /newbot.

## 2. Задеплойте Mini App
Нужен публичный HTTPS URL.

## 3. Подключите приложение
В BotFather настройте Main Mini App или кнопку Menu и укажите URL приложения.

## 4. Безопасность
Frontend получает `Telegram.WebApp.initData`.
Если позже появится backend, отправляйте именно `initData` на сервер и валидируйте его там.
Не доверяйте `initDataUnsafe` для серверной авторизации.

## 5. Бот-напоминания
Для утренних/вечерних сообщений понадобится небольшой backend или serverless function с Bot API.
Сам Mini App не может сам по себе отправлять пользователю сообщения в произвольное время.
